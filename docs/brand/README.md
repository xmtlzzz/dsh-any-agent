# README artwork

`header.jpg` is the shared hero for the English and Chinese READMEs: a blue-haired chibi whale-girl enjoying white rice at a coding desk, with subtle terminal connections behind her.

- Generated and refined with the built-in GPT Image tool on 2026-11-02.
- The selected version includes the requested slimmer cheeks and leg proportions.
- Exported as an optimized progressive JPEG, 1983 × 793 pixels, 282,513 bytes.
- The READMEs use the public raw GitHub URL so the same image works on GitHub and npm.
- Character reference: the community-created [rice-eating DeepSeek whale-girl meme](https://www.vgover.com/news/227900).
- Visual direction: the dark desktop and blue/amber lighting in [dsh-notify-me's header](https://github.com/chromoany/dsh-notify-me/blob/main/docs/brand/header.jpg).
